# TrackIt  
Sistema de Trazabilidad y Gestión de Activos con QR

## Descripción
TrackIt es una aplicación diseñada para la gestión y trazabilidad de activos físicos
(herramientas, equipos e inventario) mediante el uso de códigos QR, permitiendo conocer
en todo momento su ubicación, estado y responsable.

El sistema cuenta con:
- Un backend que gestiona la lógica y persistencia de datos
- Un dashboard web para la administración de activos
- Una aplicación móvil para el escaneo y registro de movimientos

## Objetivo del proyecto
Desarrollar una solución tecnológica que permita a las organizaciones mejorar el control
de sus activos físicos, reduciendo pérdidas, optimizando el mantenimiento y aumentando
la trazabilidad.

## Tecnologías
- Backend: Django + Django Rest Framework
- Base de datos: PostgreSQL
- Dashboard Web: React
- Aplicación móvil: Flutter
- Identificación de activos: Códigos QR
