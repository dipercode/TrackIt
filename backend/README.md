# Backend – TrackIt

Este directorio contendrá el backend del sistema TrackIt.

El backend será responsable de:
- La gestión de la base de datos
- La lógica de negocio
- La exposición de una API REST
- La autenticación de usuarios
- El registro de movimientos de activos

Tecnologías previstas:
- Python
- Django
- Django Rest Framework
- PostgreSQL

El desarrollo del backend se realizará por fases, comenzando por el
diseño del modelo de datos y la configuración del proyecto Django.
