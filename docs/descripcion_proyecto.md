# Descripción del Proyecto

## 1. Título del proyecto

**TrackIt – Sistema de Trazabilidad y Gestión de Activos Físicos mediante Códigos QR**

---

## 2. Introducción

En el contexto actual de las organizaciones, la correcta gestión de los activos físicos resulta fundamental para garantizar la eficiencia operativa, la reducción de pérdidas y el control del uso de recursos. Muchas empresas y centros educativos gestionan herramientas, equipos o material inventariable de forma manual o mediante sistemas poco automatizados, lo que dificulta conocer su ubicación, estado y responsable en tiempo real.

El proyecto **TrackIt** surge como una solución tecnológica orientada a mejorar la trazabilidad y el control de activos físicos mediante el uso de códigos QR y aplicaciones multiplataforma, facilitando así una gestión más segura, organizada y eficiente.

---

## 3. Objetivo general

Desarrollar un sistema de información que permita la gestión y trazabilidad de activos físicos mediante códigos QR, proporcionando un control detallado sobre su estado, ubicación y uso, a través de una aplicación web y una aplicación móvil conectadas a un backend centralizado.

---

## 4. Objetivos específicos

* Diseñar un modelo de datos que represente los activos, usuarios y movimientos del sistema.
* Implementar un backend que gestione la lógica de negocio y el acceso a la base de datos.
* Desarrollar una API REST que permita la comunicación entre el backend, el dashboard web y la aplicación móvil.
* Crear una aplicación web para la administración de los activos (alta, modificación, consulta y control).
* Desarrollar una aplicación móvil que permita la lectura de códigos QR y el registro de movimientos de los activos.
* Registrar el historial de uso de cada activo, incluyendo fechas, usuarios y tipo de movimiento.

---

## 5. Alcance del proyecto

El proyecto TrackIt cubrirá las siguientes funcionalidades:

* Registro y gestión de activos físicos.
* Asignación de un identificador único a cada activo mediante código QR.
* Consulta del estado actual de los activos (disponible, asignado, en mantenimiento).
* Registro de movimientos de salida y devolución de activos.
* Visualización del inventario y del historial de movimientos desde un panel de administración.

Quedan fuera del alcance del proyecto, en esta fase inicial:

* Integración con sistemas externos.
* Gestión avanzada de alertas automáticas.
* Implementación completa de tecnología NFC (opcional como mejora futura).

---

## 6. Justificación

La realización de este proyecto permite aplicar de forma práctica los conocimientos adquiridos durante el ciclo formativo de Grado Superior, especialmente en áreas como desarrollo de aplicaciones, bases de datos, programación orientada a objetos y arquitectura de sistemas.

Además, TrackIt responde a una necesidad real presente en múltiples entornos profesionales, como almacenes, talleres, laboratorios o centros educativos, aportando una solución escalable y adaptable a diferentes contextos. El proyecto también fomenta el uso de buenas prácticas de desarrollo, control de versiones y documentación técnica.

---

## 7. Tecnologías previstas

* **Backend:** Python con Django y Django Rest Framework
* **Base de datos:** PostgreSQL
* **Aplicación web:** Pendiente de definición
* **Aplicación móvil:** Flutter
* **Identificación de activos:** Códigos QR

---

## 8. Metodología de desarrollo

El desarrollo del proyecto se realizará de forma incremental, siguiendo una metodología basada en pequeñas fases de planificación, implementación y revisión. Cada avance será documentado y versionado mediante la plataforma GitHub, permitiendo el seguimiento del progreso y la evolución del sistema.

---

## 9. Resultados esperados

Como resultado final se espera obtener un sistema funcional que permita gestionar y controlar activos físicos de forma eficiente, demostrando la correcta aplicación de los conocimientos técnicos y metodológicos adquiridos durante el ciclo formativo.
